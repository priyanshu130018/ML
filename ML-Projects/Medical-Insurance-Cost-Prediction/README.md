# Medical Insurance Cost Prediction

A notebook project that predicts individual medical insurance charges from demographic and lifestyle features.

## Dataset

- Source: [Medical Cost Personal Dataset on Kaggle](https://www.kaggle.com/datasets/mirichoi0218/insurance)
- Local path: `data/raw/insurance.csv`
- Download the dataset separately. It is excluded from GitHub by the repository `.gitignore`.

## Usage

1. Download `insurance.csv` from Kaggle into the `data/raw` directory.
2. Open `train.ipynb` in Jupyter Notebook or JupyterLab.
3. Run the notebook cells in order.

```bash
jupyter notebook train.ipynb
```

The generated model file is also excluded from GitHub.
