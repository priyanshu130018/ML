# Time Series

Notebook workflows for analyzing trends, seasonality, forecasting, and time-dependent observations.

## Usage

Open Time_Series_Models_Workflow.ipynb and execute the cells in order.

## Dataset

Use the dataset specified in the notebook or download a time-series dataset from [Kaggle](https://www.kaggle.com/search?q=time+series+forecasting+dataset). Store it under data/raw/.
