# Semi-Supervised Learning

Examples of training models with a combination of labelled and unlabelled observations.

## Usage

Open Semi_Supervised_Learning.ipynb and run the notebook after installing the required Python packages.

## Dataset

Use the dataset referenced by the notebook or find a suitable dataset through [Kaggle](https://www.kaggle.com/search?q=semi-supervised+learning+dataset). Store local data under data/raw/.
