# Recommendation Systems

Examples of recommendation workflows, including collaborative filtering and similarity-based recommendations.

## Usage

Open Recommendation_Systems_All_Models_Workflow_Revision.ipynb and run the cells after installing the notebook dependencies.

## Dataset

Recommended source: [MovieLens datasets](https://grouplens.org/datasets/movielens/). A Kaggle mirror is available [here](https://www.kaggle.com/datasets/grouplens/movielens-20m-dataset). Save downloaded files under data/raw/.
