# Unsupervised Learning

Notebook examples for clustering and reducing the dimensionality of datasets without labelled targets.

## Folders

- Clustering/ - clustering workflows.
- Dimensionality Reduction/ - PCA and dimensionality-reduction workflows.

## Usage

Open the notebook in the relevant folder and run the cells sequentially. Place downloaded datasets inside data/raw/.

## Dataset Sources

- [Red Wine Quality Dataset on Kaggle](https://www.kaggle.com/datasets/uciml/red-wine-quality-cortez-et-al-2009)
- [Kaggle clustering dataset search](https://www.kaggle.com/search?q=clustering+dataset)
