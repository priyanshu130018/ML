# Dimensionality Reduction

Workflows for reducing feature dimensions while preserving useful information.

## Notebook

Open Dimensionality_Reduction.ipynb and run the cells in order.

## Dataset

The example uses the [Red Wine Quality dataset](https://www.kaggle.com/datasets/uciml/red-wine-quality-cortez-et-al-2009). Download winequality-red.csv into data/raw/.

`	ext
data/raw/winequality-red.csv
`

Dataset files are ignored by Git and must not be uploaded.
