# Anomaly Detection

Notebook-based examples for detecting unusual observations and outliers in data.

## Usage

Open Anomaly_Detection_Models_Workflow.ipynb, install the required Python packages, and run the notebook cells in order.

## Dataset

Use the dataset specified in the notebook or download a suitable anomaly-detection dataset from [Kaggle](https://www.kaggle.com/search?q=anomaly+detection+dataset). Store it under data/raw/; datasets are intentionally excluded from GitHub.
