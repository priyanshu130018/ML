# Regression

Regression examples for predicting continuous numerical values.

## Notebook

Open Regression.ipynb and run the cells in order.

## Dataset

The example uses the [Medical Cost Personal Dataset](https://www.kaggle.com/datasets/mirichoi0218/insurance). Download insurance.csv into data/raw/.

`	ext
data/raw/insurance.csv
`

Dataset files are ignored by Git and must not be uploaded.
