# Supervised Learning

Classification and regression notebooks demonstrating common supervised machine learning algorithms.

## Folders

- Classification/ - classification workflows and the Titanic dataset example.
- Regression/ - regression workflows using medical insurance cost data.

## Usage

Open the notebook in the relevant folder. Datasets belong in that folder's data/raw/ directory and are not committed to GitHub.

## Dataset Sources

- [Titanic Competition on Kaggle](https://www.kaggle.com/competitions/titanic)
- [Medical Cost Personal Dataset on Kaggle](https://www.kaggle.com/datasets/mirichoi0218/insurance)
