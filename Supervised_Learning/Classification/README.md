# Classification

Classification examples covering binary and multiclass prediction workflows.

## Notebook

Open Classification.ipynb and run the cells in order.

## Dataset

The example uses the [Titanic dataset](https://www.kaggle.com/competitions/titanic). Download 	rain.csv, 	est.csv, and gender_submission.csv into data/raw/.

`	ext
data/raw/
+-- train.csv
+-- test.csv
+-- gender_submission.csv
`

Dataset files are ignored by Git and must not be uploaded.
